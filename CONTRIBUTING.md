# Contributing

Thank you for helping improve `gracefulshutdown`.

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).

1. Open an issue for significant API changes before implementation.
2. Include tests for behavioral changes.
3. Run `go test -race ./...` and `go vet ./...`.
4. Keep the core package free of framework-specific dependencies.
